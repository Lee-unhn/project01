# MediaPipe 手勢辨識電腦控制專案

## 專案總覽

本專案利用 MediaPipe 的即時手勢辨識技術，透過電腦攝影機捕捉使用者的手部動作，實現對桌面應用程式視窗的直觀控制。

---

## 主要功能

### 手勢控制 (Gesture Controls)

*   **視窗切換**: 透過「握拳」和「食指向上」手勢，在不同應用程式之間快速切換。
*   **視窗聚焦**: 使用「勝利」手勢，將本應用程式的視窗帶到最前端。
*   **應用程式關閉**: 使用「張開手掌」手勢安全地關閉本應用程式。

### 介面與使用者體驗 (UI/UX Features)

*   **即時狀態欄**: 畫面底部提供一個半透明的狀態欄，清晰顯示當前偵測到的手勢、計時器狀態等，避免資訊與攝影機畫面混淆。
*   **指令提示面板**: 畫面右側提供一個靜態的指令提示面板，列出所有可用的手勢及其功能，方便使用者隨時查閱。
*   **動作冷卻系統**: 在觸發一個手勢動作後，系統會進入 2 秒的冷卻時間，並在畫面上顯示提示，有效防止因手勢殘留而導致的連續誤觸。
*   **視覺化手部骨架**: 在畫面上即時繪製手部的 21 個關節點和骨架，提供最直接的辨識結果回饋。

## 手勢操作指南

| 手勢 | 名稱 (英文) | 持續時間 | 功能 |
| :--- | :--- | :--- | :--- |
| ✊ | `Closed_Fist` | 0.3 秒 | 切換到 **下一個** 視窗 (`Alt+Tab`) |
| ☝️ | `Pointing_Up` | 0.3 秒 | 切換到 **上一個** 視窗 (`Alt+Shift+Tab`) |
| ✌️ | `Victory` | 0.3 秒 | 將 **本應用程式視窗** 帶到最前面 |
| 🖐️ | `Open_Palm` | 2.0 秒 | **關閉** 本應用程式 |

**注意:** 手勢的英文名稱為模型辨識出的實際名稱。程式會在命令列 (console) 中即時印出 `Detected gesture: [gesture_name]`，如果手勢無效，請以此處的名稱為準。

## 環境設置與安裝

1.  **前置條件**:
    *   Python 3.8 或更高版本
    *   電腦已連接攝影機

2.  **下載專案**:
    *   將本專案下載或 clone 到您的本機。

3.  **安裝相依套件**:
    *   在專案根目錄下，透過命令列執行以下指令：
    ```bash
    pip install -r requirements.txt
    ```

---

## 如何執行

*   在專案目錄下，執行主程式：
    ```bash
    python app.py
    ```

## 如何退出

*   在應用程式視窗中，按下 `q` 鍵。
*   或做出「張開手掌」(`Open_Palm`) 手勢並持續 2 秒。
